# Text-only models in visual games

Game enrollment rejected DeepSeek Flash because Visual Mode required an image-capable primary and removed text-only recovery routes. Game creation and startup enforced the same restriction.

Visual Mode is presentation and optional scene context, not model eligibility. Preserve selected routes and adapt optional scene messages at each provider attempt. Text-only models receive canonical room participants, observable cues, and performance instructions. Keep frozen context authority unchanged; private request evidence records the adapted request. Required image inputs outside this scene contract still fail provider validation.

Regression coverage checks text-only primaries and recovery routes, form submission, per-model image adaptation, source immutability, and actual dispatch evidence.
