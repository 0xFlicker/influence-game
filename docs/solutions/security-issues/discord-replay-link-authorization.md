# Reauthorize Discord replay links and follow-ups

A valid House share link can open a viewer page that Discord’s current
conversation has no authority to discuss. The Discord resolver applies the
conversation’s game visibility after parsing the link or resolving its short
code. It returns only a canonical reference, URL and safe navigation context.
The existing result, game and profile readers supply substantive evidence.

An Omniscient cursor belongs to its original audience. When the grant only
permits Mystery, drop the cursor, cue and time rather than interpreting them
against the Mystery projection. Conversely, explicit Mystery links can narrow
an otherwise Omniscient game or scene read. The signed image reference carries
that narrowing through download.

Extract reply subjects from successful typed tool results. Keep DM history
bound to the current verified link and access lane. Reauthorize its references
before they reach the model and recheck the exact outgoing resource URLs
before delivery. A previous reply can identify the subject. Current House
records supply the facts and ensure the text, link and image use the same
audience.
