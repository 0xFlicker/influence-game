# Private discussion passes and thought-only replay

Player observations now exclude silent discussion records, including unavailable responses. Their conversation view contains only byte allowances and current-turn redirection constraints; it does not expose the speaker queue, offers, next/previous scheduled actor, silent/unavailable IDs or end reason. Player history cursors and contribution references count speech only. Provider requests and schemas use the same visible reference numbers; decoding maps the reply reference back to its canonical ID before storing the accepted decision. Canonical events, complete provider evidence and private thinking remain unchanged. Public ballots, abstentions and voting order remain visible.

Omniscient watch metadata includes optional thought-only positions for deliberate passes. Normal playback filters them out. With Show thinking enabled, the existing room/portrait scene focuses the passing player, displays the saved thought, zooms out and immediately advances. There is no spoken message, invented Pass label, or extra speech hold. The director waits for thought loading before starting these zero-speech positions; missing/error responses release the position. Unavailable responses do not become deliberate pass shots. Thinking-only timing uses the same thought duration and camera return as spoken turns.

Historical games retain their original observations and thinking, including references to passes that were exposed when those games ran. No provider calls were made to rewrite or regenerate them. Browser verification used the completed API game `pure-beige-snow`, at cursor 14 and following passes. It displayed Lyra's saved thought without a speech bubble; disabling thinking during Mira's pass jumped to Zara's next spoken contribution. Consecutive pass shots advanced normally. The screenshot is saved privately under `packages/engine/docs/simulations/v9-api-silence-evaluation/verification/`.
